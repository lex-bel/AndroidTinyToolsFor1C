# AndroidTinyToolsFor1C

Набор дополнительных функций для мобильного приложения 1С под Android.

Компонента поддерживает:

- сканирование штрихкодов камерой устройства;
- работу с Bluetooth-сканером штрихкодов;
- печать на мобильных принтерах этикеток по Bluetooth и сети (ZPL, TSPL, CPCL);
- HTTP-сервер с поддержкой входящих `POST` и `PUT` запросов;
- подписку на широковещательные сообщения Android;
- получение информации об устройстве (модель, производитель, `Android ID`, IP-адрес, уровень сигнала Wi-Fi);
- вибрацию;
- короткий звуковой сигнал;
- `Toast`-сообщения;
- генерацию QR-кода.

## Методы компоненты

### 1. Получение идентификатора устройства

Возвращает `Android ID` текущего устройства.

Пример:

```bsl
Перем AndroidTools;

Процедура ПриОткрытии()

    Сообщить("DeviceId: " + AndroidTools.GetDeviceId());
КонецПроцедуры
```

### 2. Сканирование камерой устройства

`StartCameraBarcodeScanner([Подсветка], [РежимСканирования], [ТекстПодсказки])`

Открывает встроенный сканер с использованием камеры устройства. Поддерживаются линейные штрихкоды, `QR` и `Data Matrix`.

После успешного сканирования генерируется внешнее событие:

- Источник: `AndroidTinyTools`
- Событие: `CameraBarcode`
- Данные: считанное значение кода

Параметры:

- `Подсветка` — `Истина/Ложь`, включает фонарик сразу при запуске. По умолчанию `Ложь`.
- `РежимСканирования`:
  - `0` — универсальный режим (по умолчанию);
  - `1` — быстрый режим для линейных 1D-штрихкодов;
  - `2` — только `QR`;
  - `3` — только `Data Matrix`;
  - `4` — `QR + Data Matrix`.
- `ТекстПодсказки` — строка, отображаемая внизу экрана во время сканирования. Необязательный, по умолчанию пустой.

Интерактивное управление областью сканирования:

- на экране показывается рамка с уголками и ручками по центру каждого края;
- область можно изменить прямо на экране, потянув за угол (изменяет обе стороны) или за середину края (изменяет одну сторону);
- размер области сохраняется между вызовами;
- при первом запуске используется пресет под выбранный режим сканирования.

Цифровой зум:

- внизу экрана расположена полоса регулировки цифрового зума;
- значение зума отображается рядом с ползунком (например, `2.0x`);
- уровень зума сохраняется между вызовами.

`StopCameraBarcodeScanner()`

Принудительно закрывает окно сканирования.

Пример:

```bsl
Перем AndroidTools;

Процедура ПриОткрытии()
    AndroidTools = Новый("AddIn.AndroidTinyTools");
КонецПроцедуры

Процедура СканироватьКомандой(Команда)
    AndroidTools.StartCameraBarcodeScanner();
КонецПроцедуры

Процедура ОбработкаВнешнегоСобытия(Источник, Событие, Данные)
    Если Источник = "AndroidTinyTools" И Событие = "CameraBarcode" Тогда
        Сообщить("Сканировано камерой: " + Данные);
    КонецЕсли;
КонецПроцедуры
```

Примеры вызова:

```bsl
// Без параметров — универсальный режим
AndroidTools.StartCameraBarcodeScanner();

// Быстрый режим для линейных штрихкодов
AndroidTools.StartCameraBarcodeScanner(Ложь, 1);

// Data Matrix с включённым фонариком
AndroidTools.StartCameraBarcodeScanner(Истина, 3);

// Со строкой-подсказкой внизу экрана
AndroidTools.StartCameraBarcodeScanner(Ложь, 0, "Наведите камеру на штрихкод");

// Закрыть сканер вручную
AndroidTools.StopCameraBarcodeScanner();
```

Замечания по производительности:

- для линейных кодов лучше использовать режим `1` — декодер работает быстрее на ограниченном наборе форматов;
- для маркировки `Data Matrix` лучше использовать режим `3`;
- слишком маленькая область распознавания ускоряет поиск, но пользователю сложнее навести камеру.

### 3. Работа с Bluetooth-сканером

`GetBluetoothDevicesList()`

Возвращает строку со списком сопряжённых Bluetooth-устройств в формате:

```text
ИмяУстройства///MAC-адрес
```

Каждое устройство отделяется переводом строки.

`StartBluetoothScannerHandler(<MAC-адрес>)`

Запускает обработчик сообщений от Bluetooth-сканера.

`StopBluetoothScannerHandler()`

Останавливает обработчик сообщений от Bluetooth-сканера.

`IsBluetoothScannerHandlerConnected()`

Возвращает `Истина`, если подключение к Bluetooth-сканеру установлено.

После успешного сканирования генерируется внешнее событие:

- Источник: `AndroidTinyTools`
- Событие: `Barcode`
- Данные: считанное значение кода

Пример:

```bsl
Перем AndroidTools;

Процедура ПриОткрытии()
    AndroidTools = Новый("AddIn.AndroidTinyTools");
КонецПроцедуры

Процедура ПодключитьСканер(Команда)
    СписокУстройств = AndroidTools.GetBluetoothDevicesList();
    МассивСтрок = СтрРазделить(СписокУстройств, Символы.ПС);

    Если МассивСтрок.Количество() = 0 Тогда
        Сообщить("Bluetooth-устройства не найдены");
        Возврат;
    КонецЕсли;

    ДанныеУстройства = СтрРазделить(МассивСтрок[0], "///");
    MACАдрес = ДанныеУстройства[1];
    AndroidTools.StartBluetoothScannerHandler(MACАдрес);
КонецПроцедуры

Процедура ОбработкаВнешнегоСобытия(Источник, Событие, Данные)
    Если Источник = "AndroidTinyTools" И Событие = "Barcode" Тогда
        Сообщить("Сканировано Bluetooth-сканером: " + Данные);
    КонецЕсли;
КонецПроцедуры
```

### 4. Обработка событий от нескольких источников

Если в приложении используется и камера, и Bluetooth-сканер, имена событий позволяют их различить:

| Источник сканирования | Имя события |
|---|---|
| Камера устройства | `CameraBarcode` |
| Bluetooth-сканер | `Barcode` |

```bsl
Процедура ОбработкаВнешнегоСобытия(Источник, Событие, Данные)
    Если Источник <> "AndroidTinyTools" Тогда
        Возврат;
    КонецЕсли;

    Если Событие = "CameraBarcode" Тогда
        Сообщить("Камера: " + Данные);
    ИначеЕсли Событие = "Barcode" Тогда
        Сообщить("Bluetooth: " + Данные);
    КонецЕсли;
КонецПроцедуры
```

### 5. Подписка на broadcast-сообщения Android

`StartBroadcastReceiver(<ИмяСобытия>, <ИмяПараметра>)`

При получении сообщения вызывает обработчик `ОбработкаВнешнегоСобытия`.

Имя внешнего события соответствует значению параметра `<ИмяСобытия>`.

Пример:

```bsl
Перем AndroidTools;

Процедура ПриОткрытии()
    AndroidTools = Новый("AddIn.AndroidTinyTools");
    AndroidTools.StartBroadcastReceiver("com.google.android.c2dm.intent.RECEIVE", "data");
КонецПроцедуры
```

Важно: переменная с объектом компоненты должна оставаться доступной, пока подписка нужна приложению.

### 6. Вибрация

`Vibrate([<ДлительностьВМиллисекундах>])`

По умолчанию: `500`.

Пример:

```bsl
AndroidTools.Vibrate(300);
```

### 7. Звуковой сигнал

`Beep([<КодСигнала>], [<ДлительностьМс>])`

По умолчанию используется код `28`, длительность `200` мс.

`<КодСигнала>` — числовая константа класса `ToneGenerator` из Android SDK.
Доступные значения: https://developer.android.com/reference/android/media/ToneGenerator

Пример:

```bsl
AndroidTools.Beep();
AndroidTools.Beep(24);
AndroidTools.Beep(24, 500);
```

`Toast(<Текст>)`

Показывает стандартное всплывающее сообщение Android.

Пример:

```bsl

```

### 9. Генерация QR-кода

`GenerateQrCodeBase64(<Текст>, <Размер>)`

Генерирует QR-код в формате PNG и возвращает `BASE64`-строку с двоичными данными картинки.

Пример:

```bsl
Base64PNG = AndroidTools.GenerateQrCodeBase64("Текст для QR", 512);
```

### 10. HTTP-сервер

`StartHttpServer([<Порт>], [<ТаймаутОтветаМс>])`

Запускает встроенный HTTP-сервер. Поддерживаются входящие `POST` и `PUT` запросы.
При получении запроса компонент генерирует внешнее событие:

- Источник: `AndroidTinyTools`
- Событие: `http_request`
- Данные: JSON со свойствами `method`, `uri`, `path`, `query`, `data`, `body`, `remote_address`, `headers`

Имена заголовков внутри `headers` приводятся к безопасному для 1С формату `snake_case`.
Например: `User-Agent` → `user_agent`, `Content-Type` → `content_type`.

`HttpServerRespond(<ТелоОтвета>)`

Передаёт HTTP-ответ для текущего обрабатываемого запроса.

`StopHttpServer()`

Останавливает сервер.

Пример:

```bsl
AndroidTools.StartHttpServer(8080, 30000);

Процедура ОбработкаВнешнегоСобытия(Источник, Событие, Данные)
    Если Источник = "AndroidTinyTools" И Событие = "http_request" Тогда
        JSON = РазобратьJSON(Данные);
        JSON.data = "Данные";
        AndroidTools.HttpServerRespond(СформироватьJSON(JSON));
    КонецЕсли;
КонецПроцедуры
```

### 11. Информация об устройстве

`GetDeviceInfo()`

Возвращает JSON-строку с информацией об устройстве и сети.

Поля JSON:

| Поле | Тип | Описание |
|------|-----|----------|
| `model` | Строка | Модель устройства (`Build.MODEL`), например `"Pixel 6"` |
| `manufacturer` | Строка | Производитель (`Build.MANUFACTURER`), например `"Google"` |
| `product` | Строка | Код продукта (`Build.PRODUCT`), например `"oriole"` |
| `device_id` | Строка | `Android ID` устройства |
| `ip_address` | Строка | IP-адрес устройства (IPv4) |
| `wifi_rssi` | Число | Уровень сигнала Wi-Fi в дБм (0, если Wi-Fi не подключён). Типичный диапазон: от `-30` (отличный) до `-90` (слабый) |

Пример:

```bsl
Перем AndroidTools;

Процедура ПриОткрытии()
    AndroidTools = Новый("AddIn.AndroidTinyTools");
КонецПроцедуры

Процедура ПоказатьИнформациюОбУстройстве(Команда)
    Инфо = AndroidTools.GetDeviceInfo();
    ДанныеJSON = Новый ЧтениеJSON;
    ДанныеJSON.УстановитьСтроку(Инфо);
    Устройство = ПрочитатьJSON(ДанныеJSON);
    Сообщить("Модель: " + Устройство.model);
    Сообщить("Производитель: " + Устройство.manufacturer);
    Сообщить("Продукт: " + Устройство.product);
    Сообщить("Device ID: " + Устройство.device_id);
    Сообщить("IP-адрес: " + Устройство.ip_address);
    Сообщить("Wi-Fi RSSI: " + Устройство.wifi_rssi + " дБм");
КонецПроцедуры
```

### 12. Печать на мобильных принтерах (ZPL, TSPL, CPCL)

Печать на мобильных принтерах этикеток по Bluetooth (SPP) или по сети (TCP/IP, обычно порт `9100`).
Поддерживаются языки принтеров `ZPL` (Zebra), `TSPL` (TSC), `CPCL` (Zebra/Zebra-совместимые мобильные).

Все методы возвращают JSON-строку с результатом (кроме `PrinterDisconnect` и `PrinterIsConnected`).

`PrinterConnect(<ТипАдреса>, <Адрес>, [<Порт>], [<ТаймаутМс>])`

Подключается к принтеру. Компонента поддерживает одно активное подключение:
повторный вызов закрывает предыдущее соединение и открывает новое.

Параметры:

- `ТипАдреса` — строка:
  - `"ipaddress"` — сетевой принтер (также принимаются `"ip"`, `"network"`, `"tcp"`, `"wifi"`);
  - `"macaddress"` — принтер по Bluetooth (также принимаются `"mac"`, `"bluetooth"`, `"bt"`).
- `Адрес` — IP-адрес/имя хоста (`"10.1.1.1"`) или MAC-адрес (`"XX:XX:XX:XX:XX:XX"`).
- `Порт` — TCP-порт сетевого принтера. По умолчанию `9100`. Для Bluetooth игнорируется.
- `ТаймаутМс` — таймаут подключения и операций ввода-вывода. По умолчанию `5000`.

Возвращает JSON: `{"success": Булево, "error": Строка, "type": "bluetooth"|"network"}`.

Для Bluetooth-принтера устройство должно быть предварительно сопряжено в настройках Android.
Список сопряжённых устройств с MAC-адресами можно получить методом `GetBluetoothDevicesList()`.

На Android 12+ (API 31+) при первом обращении запрашивается разрешение `BLUETOOTH_CONNECT`.
Если разрешения не было — метод вернёт ошибку, а система покажет диалог запроса;
после выдачи разрешения вызов нужно повторить.

`PrinterPrint(<Язык>, <Данные>, [<Кодировка>])`

Отправляет задание на печать в подключенный принтер.

Параметры:

- `Язык` — `"ZPL"`, `"TSPL"` или `"CPCL"`. Пустая строка — передать данные как есть.
  Для `TSPL` и `CPCL` компонента автоматически добавляет перевод строки в конце задания, если его нет.
- `Данные` — текст задания печати на выбранном языке.
- `Кодировка` — кодировка, в которой данные передаются принтеру.
  Поддерживаются: `UTF-8` (по умолчанию), `CP866`, `CP1251`, `LATIN1` и другие имена кодировок Java.
  Для кириллицы в `ZPL` обычно используется `UTF-8` вместе с командой `^CI28`,
  в `TSPL`/`CPCL` — кодировка, соответствующая загруженному в принтер шрифту (часто `CP866` или `CP1251`).

Возвращает JSON: `{"success": Булево, "error": Строка, "bytes_sent": Число}`.

`PrinterGetStatus([<Язык>])`

Запрашивает статус принтера. Команда запроса зависит от языка:

- `ZPL` — `~HS`;
- `TSPL` — `ESC !?`;
- `CPCL` — `ESC h` (интерпретация битов может отличаться у разных производителей — смотрите поле `raw`).

Без параметра (или с пустой строкой) возвращает только состояние подключения.

Возвращает JSON со свойствами (набор зависит от языка):

| Поле | Тип | Описание |
|------|-----|----------|
| `success` | Булево | Запрос выполнен без ошибок |
| `connected` | Булево | Есть активное подключение |
| `ready` | Булево | Принтер готов к печати |
| `paper_out` | Булево | Закончилась бумага |
| `paused` | Булево | Принтер на паузе |
| `head_open` | Булево | Открыта крышка (ZPL, TSPL) |
| `ribbon_out` | Булево | Закончился риббон (ZPL, TSPL) |
| `paper_jam` | Булево | Замятие бумаги (TSPL) |
| `printing` / `busy` | Булево | Идёт печать (TSPL / CPCL) |
| `raw` | Строка | Необработанный ответ принтера (для TSPL/CPCL — hex-байт) |
| `error` | Строка | Текст ошибки, если есть |

`PrinterIsConnected()`

Возвращает `Истина`, если подключение к принтеру активно. Принтер при этом не опрашивается.

`PrinterDisconnect()`

Закрывает соединение с принтером. Соединение также закрывается автоматически при выгрузке компоненты.

Пример (сетевой принтер, ZPL):

```bsl
Перем AndroidTools;

Процедура ПриОткрытии()
    AndroidTools = Новый("AddIn.AndroidTinyTools");
КонецПроцедуры

Процедура НапечататьЭтикетку(Команда)

    // 1. Подключение принтера
    Результат = ПрочитатьРезультат(AndroidTools.PrinterConnect("ipaddress", "10.1.1.1", 9100, 5000));
    Если Не Результат.success Тогда
        Сообщить("Ошибка подключения: " + Результат.error);
        Возврат;
    КонецЕсли;

    // 2. Проверка статуса
    Статус = ПрочитатьРезультат(AndroidTools.PrinterGetStatus("ZPL"));
    Если Статус.success И Не Статус.ready Тогда
        Сообщить("Принтер не готов (нет бумаги/пауза/открыта крышка)");
    КонецЕсли;

    // 3. Отправка данных на печать
    Данные = "^XA^CI28"
        + "^FO50,50^A0N,40,40^FDТестовая этикетка^FS"
        + "^FO50,120^BY2^BCN,80,Y,N,N^FD123456789^FS"
        + "^XZ";
    Результат = ПрочитатьРезультат(AndroidTools.PrinterPrint("ZPL", Данные, "UTF-8"));
    Если Не Результат.success Тогда
        Сообщить("Ошибка печати: " + Результат.error);
    КонецЕсли;

    // 4. Отключение принтера
    AndroidTools.PrinterDisconnect();

КонецПроцедуры

Функция ПрочитатьРезультат(JSONСтрока)
    Чтение = Новый ЧтениеJSON;
    Чтение.УстановитьСтроку(JSONСтрока);
    Возврат ПрочитатьJSON(Чтение);
КонецФункции
```

Пример (Bluetooth-принтер, TSPL):

```bsl
Процедура НапечататьПоBluetooth(Команда)

    Результат = ПрочитатьРезультат(
        AndroidTools.PrinterConnect("macaddress", "00:11:22:33:44:55"));
    Если Не Результат.success Тогда
        Сообщить("Ошибка подключения: " + Результат.error);
        Возврат;
    КонецЕсли;

    Данные = "SIZE 58 mm,40 mm" + Символы.ПС
        + "GAP 2 mm,0" + Символы.ПС
        + "CLS" + Символы.ПС
        + "TEXT 30,30,""0"",0,10,10,""Тест""" + Символы.ПС
        + "BARCODE 30,90,""128"",70,1,0,2,2,""123456789""" + Символы.ПС
        + "PRINT 1";
    Результат = ПрочитатьРезультат(AndroidTools.PrinterPrint("TSPL", Данные, "CP866"));
    Если Не Результат.success Тогда
        Сообщить("Ошибка печати: " + Результат.error);
    КонецЕсли;

    AndroidTools.PrinterDisconnect();

КонецПроцедуры
```

Пример задания CPCL:

```bsl
Данные = "! 0 200 200 320 1" + Символы.ПС
    + "TEXT 4 0 30 40 Тест" + Символы.ПС
    + "BARCODE 128 1 1 50 30 120 123456789" + Символы.ПС
    + "FORM" + Символы.ПС
    + "PRINT";
Результат = ПрочитатьРезультат(AndroidTools.PrinterPrint("CPCL", Данные, "CP1251"));
```

## Сборка

Для сборки используется:

- Android Gradle Plugin `8.9.1`
- Gradle Wrapper `8.11.1`
- `compileSdkVersion 34`
- `targetSdkVersion 34`

Release-сборка (основная):

```powershell
.\gradlew.bat assembleRelease
```

Перед сборкой версия компоненты автоматически увеличивается на `+1`. После сборки в каталоге `AndroidTools` создаётся ZIP-пакет вида `AndroidTinyTools_<версия>.zip`.

Debug-сборка (без увеличения версии):

```powershell
.\gradlew.bat assembleDebug
```
